# Web交互原型：第一轮

## 本轮范围
单页工作区切换，Next.js App Router宿主。暂未拆分正式业务URL。
- 广场演示内容、搜索与题材筛选、详情与费用说明。
- 四步剧本编辑：基本信息、世界与开局、主要角色、场景参考。
- 角色模板创建和添加进剧本。
- 独立游玩快照、行动输入、建议卡片、历史记录、退出及继续。
- 浏览器localStorage持久化，非云同步。示例剧本不是平台固定剧情承诺。

## 刻意未接入
Figma文件、真实视频与音频、LangChain、登录、云端数据库、审核和公开发布、Tauri。场景为远端Unsplash静态图片，网络失败仍保留背景色和可操作界面。不得将该原型称为实时模型已接入。

## 文件结构
- apps/web/app：Next入口与样式。
- apps/web/components：广场/管理工作区、编辑器、模拟游玩、数据与本地存储。
- packages/domain/src/story.ts：不可变快照、存档行动、必填校验。
- packages/ui/src/tokens.css：共享视觉变量。

## 运行
根目录执行 `pnpm install`、`pnpm dev`，默认127.0.0.1:3100。
检查：`pnpm test`、`pnpm typecheck`、`pnpm build`。
具体执行结果将在本轮验证后记录。
