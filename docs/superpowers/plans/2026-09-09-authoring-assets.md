# 一期创作链路：剧本、角色和图片

范围：实现已讨论的角色复用、自定义图片与独立游玩快照，不扩大为二期物体点击。

- 角色模板完整复制外貌/说话习惯/边界；关系由当前剧本独立定义，替换角色不遗留前一个人的头像与资料。
- 图片用途明确为封面、角色参考、开场画面。原始文件不进 localStorage；本地 IndexedDB 保存图片，剧本仅保存资产引用。
- 上传前检查类型/体积，解码后检查尺寸；实际存储失败保留旧图。清除选择不删除可能被历史存档引用的资产。
- 编辑器、详情和广场通过统一图片解析展示，缺失资产明确提示，不随机借用其他人物。
- 准备页显示「本机可见 / 尚未发送模型」；官方模型参数映射另行核对，不自动发送私人图片。
- 单测领域复制与角色切换、图片验证；类型/构建和浏览器上传/刷新走查。

供应商协议只读核对由 Descartes 并行完成；本轮不执行付费生成或发布上传。
