# 供应商—模型映射改造

用户要求：供应商与模型分层，不将 fal 等供应商和 MiniMax 模型混为一体。

- 纯目录定义供应商、模型与部署映射，能力属于具体部署，不属于供应商品牌。
- 服务端 VIDEO_PROVIDER / VIDEO_MODEL 显式选择；不默认回退 fal。
- 浏览器运行时通过映射解析 adapter；界面分别展示供应商与模型。
- MiniMax 官方 H3 当前核对为异步任务接口，目录登记，不伪造与 Director 等价的实时接入。
- 先测未知组合、缺配置、非实时部署及密钥不外泄，再接线验证。

暂不开放客户端任意 baseURL 或使用跨供应商密钥；生产认证/额度约束继续保留。
