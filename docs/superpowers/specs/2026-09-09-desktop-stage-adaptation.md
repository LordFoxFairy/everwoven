# 桌面视频舞台：本轮实现与验收

日期：2026-09-09。根据用户最新确认，撤销 9:16 内容优先。

## 产品决定

- 产品是桌面 Web / 桌面应用，而非桌面里嵌一块手机屏幕。
- 舞台随窗口可用宽度、高度适配。当前生成默认横屏 16:9；9:16 仅作为用户主动选择的构图。
- 生成比例与显示尺寸分离。供应商未声明支持的尺寸不冒充支持；窗口缩放不会重启生成。
- 视频等比完整显示，不拉伸、不裁切。非同一宽高比的窗口允许留边；这不同于重新生成扩展画面。
- 表达区在舞台外独立占位，观看时仅有轻入口，主动表达时展开，没有聊天气泡流。
- 第一帧未到时不邀请玩家先发消息。连接 ready 不等于画面已播放。
- 未配置引擎仍展示玩家确认的世界、角色和开场，不只显示一张技术报错卡。

## 本轮已实现

- LiveSession：默认横屏、独立视频舞台、轻量顶部控制、画面外表达区、首画面前隐藏表达入口。
- SessionOpening：准备页共用的世界与角色上下文。
- ConfiguredLiveSession：未就绪状态沿用桌面双栏准备页，窄窗口转为单栏。
- 游玩与准备页改为珍珠白、浅灰、雾蓝；平台外壳和编辑器尚未全面换肤。
- 未修改供应商选择、真实接入门禁、用户图片或密钥；没有发起付费生成。
