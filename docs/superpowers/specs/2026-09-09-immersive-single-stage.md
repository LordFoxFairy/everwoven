# 沉浸式单舞台与可收纳交互

> 2026-09-10更新：媒体默认铺满和系统全屏由[最新规格](2026-09-10-edge-to-edge-stage.md)取代下文默认contain与底部40px评审栏要求；历史验证数据不代表新舞台尺寸。

状态：用户确认单视频＋悬浮收纳方向，本轮原型实现；完整视觉仍待用户评审。

## 取代的布局

移除“播放器＋下方大标题＋三张大卡片”的独立布局。现场是一块持续存在的媒体舞台；标题、退出、菜单、回应、输入、生成状态和异常均属于舞台上的界面层。原型评审栏是外部工具，正式产品不带。

不改动一期的生成能力边界：先生成、再播放，片段结束后才开放回应；观看／生成过程中不接收实时剧情介入。

## 显示规则

- 观看：只保留轻量标题、菜单与必要提示，没有输入框和回应列表。
- 片段结束：自动浮出默认三条情境回应；使用直接提交的话语，删除重复意图标题和大块按钮装饰。
- 选择：单击提交；其余回应退场，显示已选内容和生成状态，不声称世界后果已兑现。
- 修改：独立次级入口；鼠标悬停／键盘聚焦时可见，触屏保持可见。
- 自己回应：同一悬浮层内编辑，返回建议不提交；草稿保留。
- 收纳：关闭或 Escape 收起整个回应层；留“回应 · 等你决定”入口，草稿存在时明确提示；不会因为重复片段结束事件自动弹回。
- 换边：宽桌面可左右换位，不修改剧情；小窗口使用底部紧凑层。
- 菜单：按需打开声音／设定／退出，原型未实现音频仍明确禁用。
- 错误：独立浮层保留恢复与退出，不随回应收纳而消失。

## 单一画面与适配

舞台占可用窗口，媒体按实际比例 contain，不裁剪、不拉伸。回应打开与关闭不改变舞台尺寸。窄长窗口的横屏媒体会留出空白，这是比例适配，不把同一视频裁成竖屏；媒体位置按窗口比例固定，不随回应状态上下跳动。

回应层有最大高度与局部滚动，超长文字不撑出整页。默认左下，示例人物在右；这不是人脸识别或自动避让能力。用户可以换边或收起。未来如自动避让人物、字幕、热点，需实际区域信息与冲突策略，不从模型提示词猜测。

媒体与交互层生命周期分开。本原型在进入现场后保持媒体 DOM，更新只替换交互层；未来真实视频组件也不得因卡片开关而重新挂载、重播或重复计费。当前仍是静态图示意，并非已经接入视频。
