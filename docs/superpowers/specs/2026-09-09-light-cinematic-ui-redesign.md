## 方向选择

- 推荐：明亮电影现场。平台亲近、清楚，进入后视频成为主体。珍珠白、浅灰、少量雾蓝，不沿用深绿色管理台外壳。
- 对照：杂志式故事橱窗，视觉表达强但易被误解为固定内容销售目录。
- 对照：未来感 AI 工作台，可暴露复杂功能但易让玩家像模型操作员，不作为主游玩风格。

## 视觉约束

- 页面背景建议 #F7F8FA、表面 #FFFFFF、主要文字 #222838、强调色 #53677E；正文和次级文字的具体色值在实现时测对比度，概念图不作为无障碍通过证据。
- 展示标题可少量使用宋体，操作文字用清晰中文无衬线。避免泛用英文装饰标语。
- 中等圆角与克制阴影；玻璃材质只用于确有必要的悬浮控制，不做层层毛玻璃。
- 外层使用横向轻导航，发现（剧本广场）、我的剧本、角色库、我的游玩；窄桌面窗口需单独布局，不依赖隐藏必要入口。
- 桌面可用宽高决定舞台空间，默认横屏生成（当前 16:9），9:16 只作主动选择。按真实媒体比例 contain 显示，不以铺满为由裁切人物，不把任意窗口尺寸伪装为模型支持的生成尺寸。
- 会话内缩放仅改变显示，不重新请求生成。表达区在视频之外占位，短窗口保持最小可看画面并允许页面滚动。
- 空白是视频与控制之间的安全区，不以推荐卡或人物说明填满；小窗口仍要留出输入与退出空间。

## 新的入口

首页描述框用于创建初始设定，不是游戏里的聊天框。结构为一句体验描述＋可选角色/图片＋“构建开场”；下一步展示可修改的设定摘要，再确认素材用途/预算并开始。

“我的角色、提示模板、最近的经历”在图中示意可进入的资源，不代表已经生成或发生的故事。新用户没有经历时须有真实空状态；不会用随机示例冒充用户记录。

详细编辑器保留，作为进阶入口。AI 整理未接通时，不把写死模板或手工字段映射称为智能生成。

## 现场必须设计的六种状态

| 状态 | 主体 | 交互形态 |
| --- | --- | --- |
| 准备 | 用户确认的角色、世界、素材和预算 | 一个开始按钮，尚未生成 |
| 首画面等待 | 明确进度与取消入口 | 不放剧情选项，不用静态图冒充视频 |
| 自然观看 | 实际视频、可选字幕 | 无常驻输入框和发送按钮；保留小而可发现的自由表达入口 |
| 自由表达 | 保留现场，展开本次表达区域 | 在舞台安全区输入，收起保留草稿，不形成聊天气泡流 |
| 情境邀请 | 已经呈现的事件 | 少量有效卡片，非固定 ABCD；可忽略或用自由行动替代 |
| 中断/结束 | 真实状态、草稿与恢复条件 | 清楚的恢复/退出方式；分别显示保存与资源终止结果 |

本图只呈现入口及自然观看两态，其他状态尚未生成视觉稿。只有连续过程走查通过后，才称交互原型完成。

## 动作与层级

- 卡片、文字区有独立生命周期，不随模型每次文本输出随机移位。
- 场景变化前检查候选版本，已失效卡片退场；聚焦或输入期间保持控件稳定。
- 进入现场后平台导航退场，但重要费用、错误和退出入口保持可达。
- 转场建议短促、克制；不为了动画等待额外延迟真实视频，尊重减少动态偏好。
- 没有字幕或模型语音时不编造另一套角色对白。暂未接入语音前不展示可用录音控件。
