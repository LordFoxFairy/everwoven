# 剧本平台交互原型设计

状态：用户已批准推进方向；具体视觉待关键屏验证。本文更新旧 PRD 中缺失的剧本广场和创作管理范围，不把旧概念图当作已确认设计。

## 产品对象
- 角色模板：可复用基础人设与素材。
- 剧本草稿：世界、角色实例、玩家身份、开局、规则、视听偏好。
- 剧本发布版本：不可变快照，公开前经审核；角色模板修改不自动传播。
- 游玩存档：绑定剧本版本，运行事件独立保存；不同存档互不污染。

## 信息架构
主导航：剧本广场、我的剧本、角色库、我的游玩。账户与设置放次级入口。
广场 → 剧本详情 → 身份与费用确认 → 新建游玩 → 保存退出 → 继续。
我的剧本 → 编辑 → 检查 → 预览试玩 → 保存或发布。
角色库 → 新建或编辑 → 在剧本中添加并配置专属身份。
广场示例内容必须注明演示素材，不宣称真实用户、热度或平台预设剧情。

## 第一轮三屏
### 剧本广场
桌面基准1440×900，验证1280×800与1920×1080。轻量导航，搜索和题材筛选，封面为主的内容网格。卡片含名称、简述、角色和标签，避免虚构排行。无存档时不展示虚构的继续游玩。
### 剧本编辑器
左侧分节，中间编辑，右侧可收起的预览。分节为基础信息、世界设定、角色、玩家身份、开局、叙事规则、视听。明确草稿/保存中/已保存/失败状态。离开未保存内容时确认。第一版不用节点图编辑器。
### 实时游玩
视频是主舞台，自由输入始终可用。建议、物品、确认等由受控组件目录渲染，不执行模型生成脚本。每条动作记录待处理/已应用/失败，不能把收到输入说成画面已改变。角色和历史按需抽屉显示。

## 视觉提案
精致内容产品而非管理后台。浏览与创作采用中性浅色背景、墨色文字、少量品牌强调；游玩采用随画面退后的暗色控件。具体强调色与封面构图通过三屏比较确认，尚未定稿。统一字体、间距、圆角、焦点和状态tokens。禁止全站粉色花边、黑紫霓虹和固定数据仪表盘。人物和封面是内容素材，不把生成的整屏截图作为页面实现。

## 技术边界
Next.js/React/TypeScript Web；Tauri+Vite/React桌面薄壳；共享React业务组件不依赖Next服务端API。Tailwind+自有tokens，shadcn按需。React Hook Form+Zod编辑，TanStack Query远端数据，Zustand仅界面状态。AI SDK UI接LangChain唯一后端；视频Provider独立。Prisma只在服务端。
原型用MockRepository和MockVideoProvider，后续替换实现而非改写页面。Mock媒体明确标注，不宣称实时生成。不要现在安装全部未来依赖。

## 状态及验收
- 搜索无结果、首次空库、加载失败、保存失败可见且可恢复。
- 同一剧本能建立两个独立存档。
- 改角色模板不影响已发布快照；编辑草稿不修改旧存档。
- 详情→开始确认→游玩→退出→继续路径可操作。
- 编辑器校验必填项，保存后刷新可恢复（原型本地存储须标注非云同步）。
- 卡片允许关闭或选择；自由输入不限于建议。
- 模拟延迟、失败与重连；停止页面播放与结束服务端会话分别建模。
- 键盘可操作、焦点可见、弹层焦点回归、减少动态效果设置生效。
- Playwright检查桌面视口无横向溢出；Tauri媒体另做真机验证。

## 不在本轮
真实登录、支付、发布审核服务、实际模型接入、多人游戏、交易市场。相应按钮标注演示或未接入，不伪装成功。
