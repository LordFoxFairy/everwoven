# 原型 1.8：从一个起点，到回来继续

2026-09-10。用户已同意推进前一轮的完整体验方向。本轮是原型与功能 PRD 对齐，不是模型接入或实时生成完成。

## 设计取舍

- 保留独立 3103 原型，避免未评审 UI 覆盖 3100 的已有数据与功能。
- 不继续扩展播放器旁边的功能面板。外部是明亮个人空间，内部是一块铺满窗口的媒体舞台。
- 外部采用暖白、墨色与小面积珊瑚强调，无衬线排版；视觉样例作为可选体验入口，不冒充用户的已有经历。
- 有记录优先继续，没有记录呈现真实空状态。剧本、角色模板与演练记录是不同对象。
- 草稿与显式保存的演练记录使用独立 localStorage 名称，图片放独立 IndexedDB；不读 3100 数据，不调用模型。
- 添加显式“模拟片段就绪 / 模拟播放结束”，正常走查无需找隐藏评审开关。按钮属于设计演练，生产产品必须由真实任务/媒体事件触发。
- 两组回应仅是交互样例，第二轮明确标注未生成后果，不根据选择编造视频或共同回忆。

## 本轮实现

1. 首次进入/回访、个人剧本列表、剧本灵感、角色模板、经历记录页面。
2. 轻创建字段、进阶身份/关系/边界、角色选择与保存、图片用途/本机选择/替换。
3. 一键进入静态演练；生成与观看阶段无输入；结束后显示三项建议与自由回应。
4. 选项一键提交、独立编辑、收纳与恢复；不同轮次呈现不同的明确样例。
5. 保存剧本、保存演练退出、刷新后恢复同一阶段及草稿；新剧本不串旧角色。
6. 文字备份导出（不含图片文件）、保存失败保留内容、损坏数据不覆盖、删除选定记录前确认。
7. PRD 1.8 整理 F01–F08 功能、状态/数据、错误/费用、供应商准入、三层 Gate。历史 1.7 归档。

## 实际浏览器走查记录

环境：Codex in-app browser，本机 3103。以下为交互原型测试，不是用户研究。

- 首页初始没有个人记录；只有明确标识的视觉样例。
- 样例确认 → 开场生成示意，无聊天框；模拟就绪后观看示意，无选项；模拟结束后出现三个建议。
- 点击“你为什么想画这里？”直接进入下一段生成状态，不要求先编辑确认。
- 下一轮显示新的交互示例，标明“未生成后果”。
- 自由表达“走查草稿：我想先听你说完，下次再回答。”，收起后保留；保存离开、刷新、继续演练，再展开后文本完全保留。
- 四个尺寸的 stage 实测均等于窗口，均无文档滚动溢出：480×800、1024×768、1280×720、1440×900。
- cover → contain 保持节点；系统全屏实际出现 HTML :fullscreen；设置对话框在全屏内可访问；保存退出后 :fullscreen 清除。
- 新建时角色、地点、开场为空，未继承样例。自定义“本机素材走查”及“林 · 走查角色”后保存。
- 通过文件选择器选择本项目 scene.png，用途为“角色外观参考”；成功解码和保存，刷新后重新打开剧本，角色、图片预览和用途保持。

## 验证边界

- 原型状态机、元数据保存/失败/损坏记录、新建隔离有单元测试；图片 IndexedDB 成功路径由浏览器验证。
- 本次没有删除用户既有记录；删除隔离由单元测试覆盖，不把未执行的浏览器永久删除声称已验收。
- 没有真实生成、音频、模型建议、事实记忆、语义后果、在途费用或 Tauri 验收。
- 原型存储无跨设备同步或生产备份。元数据保存使用跨窗口写锁与对象版本冲突检查，但不等于生产数据库事务。图片和文字分库存储，文字备份不含图片，备份导入尚未实现。为保护其他窗口尚未保存的引用，当前保守保留物理图片文件，自动回收尚未实现。
- 目标用户可用性和视觉定稿未完成；浏览器走查通过只说明本次操作可用。

## 代码结构

- workspace.mjs：纯外部页面渲染。
- app.mjs：交互绑定与浏览器能力。
- model.mjs：分段演练状态机。
- library.mjs：元数据格式、存储结果和记录隔离。
- assets.mjs：本机图片读写。
- experience.css：新版外部与悬浮视觉；复用 immersive.css 的单舞台规则。

不新增框架依赖。正式应用仍按 Next.js/TypeScript + 单一 LangChain/LangGraph 执行层规划，静态原型不等于已完成迁移。

## 复核后修正与最终验证

- Maxwell 独立只读复核发现多窗口覆盖、异步图片归属、首页对象混用、角色弹窗草稿、图片清理和事实提交边界问题。主会话已处理对应实现/规格。
- 保存使用浏览器独占写锁，整库变化与正在编辑的目标记录版本分别核对；无关角色保存不更新剧本编辑基准。冲突提供另存剧本/角色/演练的出口，不静默覆盖。
- 异步图片读写期间限制冲突切换；保存图片引用前检查本机文件存在。取消即时物理清理，优先保留另一窗口可能正在使用的素材，明确剩余存储成本。
- 角色编辑关闭再打开，实测未保存性格仍在；最终保存成功。回到首页实测清空新建输入及旧角色/图片绑定。最终版本中带图片的旧剧本再次保存成功。
- 明确 PRD 的事实归并执行主体、完整播放提交边界、未确认候选与保存点幂等事务要求。
- 主仓最终测试：137 项通过；类型检查与构建通过。浏览器控制台未见页面错误。测试通过不代表真实 AI 生成或视觉已获用户接受。
