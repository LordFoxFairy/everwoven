# M0-B · 剧本草稿根对象持久化闭环

2026-09-10 · 内部根CRUD切片已验证；完整M0仍未完成。不开放HTTP、不切换浏览器数据。

## 范围与承诺

在现有Prisma/SQLite与WriteGate基础上实现剧本草稿根对象的创建、单项读取、分页列表、修改、软删除及恢复。只支持title/settings；人物和素材绑定、版本封口不在本切片。内部身份上下文单独传入，不接收用户请求体的ownerId当作身份。

- 契约沿用StorySettings的premise/playerRole/worldRules/tone和既有长度边界；未知字段拒绝，允许未完成的设定保存为草稿。
- ID/时间走统一IdFactory/Clock；createdAt不变，update/delete/restore更新updatedAt及revision。
- 写事务第一条应用数据库语句为WriteGate；回执先于资源状态/CAS检查，业务与回执同事务。
- 创建重放不创建新ID，删除重放不因已删除失败；不同内容复用commandId拒绝。重放是历史结果，读最新状态使用get。
- get/list也检查有效owner；未拥有与不存在一致。默认过滤已删对象，列表限量和稳定游标分页。
- 删除不级联删人物、素材、冻结版本或经历；当前15表、13项真实唯一、零外键保持不变。
- SQLite忙错误先透传，让调用方明确失败并使用同一commandId重试；本切片不引入隐式重试或新ID补偿。

## 实施步骤

3. 实现草稿根用例，复用旧WriteGate。旧rename探针仍保留历史验证，不作为正式update接口。
4. 根测试、类型检查、构建；独立只读评审。
5. 更新实施状态与下一门槛。

## 验证结果

- 新增28项真实文件SQLite集成测试：创建/修改/软删除/恢复、断开重开、同名允许、独立owner隔离、历史回执、不同摘要、稳定分页/游标scope、无级联删除冻结版本、输入白名单。
- 故障路径：Clock/IdFactory异常、业务写入后回执生成失败、回执插入冲突、未知存储schema/损坏回执，均不留下半成功根或回执。
- 两个独立连接同时持旧revision写入，只一方提交；失败方同键重试得到版本冲突，现有内容不被覆盖。
- 新增统一RuntimeServices（IdFactory/Clock）；时钟回退不降低updatedAt，revision仍递增；契约标量校验不依赖应用层或数据库。
- 全项目23个测试文件226项测试、runtime/Web类型检查与生产构建通过。未调用模型，未改UI、浏览器存储或用户图片。
- 只读独立审查范围内无明确P1/P2；主会话自行重新运行验证，不把代理结论替代测试。
