# 创作素材链路验收 · 2026-09-09

## 本轮已实现
- 剧本编辑器的角色模板完整复制：姓名、性格、外貌、表达习惯、边界、角色参考图。
- 关系属于剧本，不随角色模板迁移；模板复制后独立编辑。替换模板会清掉旧人物遗留字段及演示头像。
- 角色库支持创建、编辑、以角色开始新剧本；剧本中的角色可另存为模板。
- 封面、角色参考图、开场帧三种独立引用。图片经解码、格式/体积/尺寸验证，保存最大边 2048px 的本机处理副本，元数据引用进入 localStorage，二进制进入 IndexedDB。
- 导入失败保留旧图，处理期间阻止保存/离开编辑器；清除选择不物理删除历史快照可能仍引用的图片。
- 剧本列表、详情、编辑预览、游玩设定记录使用同一套本机图片解析。缺失记录明确提示。
- 详情及游玩准备区可查看本机图片状态，并明确尚未发送模型。
- 完整可见路径：角色库 → 用 TA 创作 → 保存并进入准备 → 剧本详情 → 接入准备状态。

## 官方接口核对
来源：https://platform.minimaxi.com/docs/api-reference/video-generation-v2-create

- MiniMax-H3：支持多模态参考输入。
- MiniMax-H3-Max：支持文生和首尾帧，不支持 `reference_image` 多模态参考模式。
- `first_frame` / `last_frame` 与 `reference_image` 等参考模式互斥。角色参考图不能悄悄改成首帧，也不能直接与开场图混发。
- 图片输入在官方端仍有单独的大小、宽高、比例及请求总大小约束。本机可保存不等于模型可接收。

## 后续主线及未完成项
1. 按所选供应商/模型构建图片输入计划：支持哪些角色、使用哪种模式、不兼容时明确让用户选择，封面永不作为生成输入。
2. 在服务端接通官方任务接口及素材传输；密钥不进浏览器，私人素材传输需明确用户知情。
3. 官方任务式生成到连续播放的调度：开场、后续片段、用户行动生效边界、取消与费用控制，以及端到端延迟实测。
4. 素材可用性、送达供应商、供应商接受、画面遵循参考应分开验收。
5. 本机素材导出/导入与云同步、孤立素材回收、多角色场景另列后续范围。现阶段没有云同步，清除浏览器数据会丢失本机素材。

未调用付费模型。当前官方连续生成/播放适配尚未完成；本轮交付的是创作与素材管理链路，不是已完成的实时生成引擎。
