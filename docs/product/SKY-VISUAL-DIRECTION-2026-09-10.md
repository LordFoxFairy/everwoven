# 晴空蓝 × 浅紫 · 网站视觉基准

2026-09-10 · 按用户明确的蓝、浅蓝、紫色和天空感要求，修改现有应用；不是另建原型。

## 1. 方向

明亮、空气感、安静的创造空间。浅蓝做环境，淡紫做层次，深蓝灰保证阅读；避免大面积深绿/米黄、霓虹与技术控制台视觉。天空装饰仅在首页，现场的用户视频/图片不加蓝色滤镜。

首页按用户状态分层：全空时主动作是“创建我的世界”，用CSS晴空窗口引导；只有草稿时突出继续创作；有演练时展示该用户原记录的接续入口与静态参考，不用固定人物营销横幅。示例卡片移到剧本广场并标识演练。详情见[个人入口实施记录](../implementation/PERSONAL-ENTRY-2026-09-10.md)。不加载图片生成服务或额外动画库。

## 2. 共用令牌

唯一基础令牌位置：`packages/ui/src/tokens.css`。

| 用途 | 值 |
|---|---|
| 页面底色 | `#f5f8ff` |
| 白色表面 | `#ffffff` |
| 天空浅蓝 | `#e4f2ff` |
| 淡紫 | `#ede9ff` |
| 主动作底色 | `#4264d7` |
| 浅色底上的强调文字 | `#3453c1`，不与按钮底色混用 |
| 正文 | `#233353` |
| 辅助正文 | `#566580` |
| 焦点框 | `#4d70df` |

正文配对目标4.5:1，焦点框对相邻浅色表面目标3:1。自动测试覆盖具体令牌配对，不等于全站无障碍认证。错误色保留暖红语义，不随主题改为蓝色成功提示。

## 3. 已调整界面

- 首页：浅蓝到淡紫天空背景、柔和云层、玻璃窗口装饰、清楚的创建/示例入口。
- 外壳：蓝紫品牌标记、浅色侧栏、当前导航、高对比动作、轻量演练状态标识。
- 剧本广场/我的剧本：白色卡片、蓝紫标签、清晰的搜索和筛选、轻微悬浮反馈。
- 剧本编辑器：同主题导航、输入框、说明、素材区域和侧边预览；必填符号不单独挤占一行。
- 角色库：白色卡片、浅紫表单、蓝色图片选择按钮，窄屏单列不超出内容区。
- 开始详情：保留角色画面本色，右侧浅蓝/浅紫信息区；边界、演练声明和动作层次统一。
- 共用分段舞台：只调整悬浮控件、焦点和提示配色；不缩小媒体、不改变播放/回应门禁。

## 4. 适配与保护

- 窄窗口收起侧栏文字但保留图标按钮的可访问名称；首页装饰在窄窗口隐藏，主操作仍在。
- 搜索与标题在中小窗口改为上下排布，筛选可换行，不靠隐藏横向溢出来掩盖布局问题。
- 320px、390px验收页的首页/角色表单实测document宽度等于viewport宽度；桌面首页在1280px查看截图。
- 现场保存错误移至上部；950px以下同时压缩回应/状态面板的最大高度并保留滚动，避免底部操作被错误条盖住。短屏失败态尚需专门的端到端故障注入复测。
- 装饰无交互、无读屏噪音；尊重减少动态效果设置，图片/视频像素不染色。
- 本轮不迁移存储、不改供应商、不调用模型。验收没有保存空白剧本、修改角色或上传用户素材。
